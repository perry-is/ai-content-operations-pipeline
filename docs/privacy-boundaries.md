# Privacy boundaries

The repository uses fictional source text, a fictional host, and a small synthetic reference library. It does not include real transcripts, audience or client information, production URLs, internal instruction files, private conversations, credentials, account data, or proprietary artwork.

The example passes only the fields needed to demonstrate source interpretation, content identity, output generation, and metadata. The demo performs no network calls and has no provider credentials. If a remote model is added later, data minimization and review of the exact fields sent to that provider will be required; this prototype does not implement or claim those security controls.
